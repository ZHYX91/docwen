# Support

Use GitHub issue forms for reproducible DocWen bugs and focused feature requests. Conversion, OCR,
proofreading, CLI, packaging, and GUI problems belong here. Problems that occur only inside Obsidian belong
in the DocWen Assistant repository.

Before posting, remove private document content, absolute paths, credentials, and personal data from logs,
screenshots, samples, and doctor output. Use the repository Security page for vulnerabilities; never post
exploit details publicly.
