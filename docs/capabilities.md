## State vocabulary / 状态说明

- `verified`: automated or executed acceptance evidence covers the current contract.
- `tested`: focused automated coverage exists; environment-specific checks remain part of release validation.
- `partial`: only the explicitly described subset is supported.
- `intentionally_removed`: the capability is not part of the supported product surface.

- `verified`：当前契约已有自动化或已执行验收覆盖。
- `tested`：已有聚焦自动化覆盖；环境相关检查仍由发布验收负责。
- `partial`：仅支持本行明确描述的子集。
- `intentionally_removed`：该能力不属于当前支持面。
