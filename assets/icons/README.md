# Interface icons

Interface controls use the Fluent System Icons Regular 24 family. The application brand and the empty-state illustration are separate assets. Render interface icons through `load_svg_icon`; keep their geometry in vector form and let the palette provide normal and disabled colors. Status icons use the corresponding semantic color.

These files come from Microsoft Fluent System Icons at commit `9cf8af0f95a555918a60b8147a2f33a6a1248442` under the adjacent MIT license. Only the foreground fill is normalized to `#000` for theme adaptation.
