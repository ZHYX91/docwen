DocWen corresponding source
===========================

Download the source matching the numeric release and its build scripts:
https://github.com/ZHYX91/docwen/releases

Every official package adds its build commit to this file. The repository contains
the project code, uv.lock, build and release scripts, and the asset manifests.
Source is offered without charge. See LICENSE for DocWen's AGPL-3.0-or-later terms
and LICENSE_THIRD_PARTY.txt and licenses/ for third-party terms. The package
extracts and runs outside the Microsoft Store as the Windows portable release.

Other redistributed components
------------------------------
OpenCV Python wheel 4.13.0.92 and its build inputs: https://github.com/opencv/opencv-python/tree/92
OpenCV core 4.13.0: https://github.com/opencv/opencv/tree/4.13.0
The OpenCV wheel's third-party notices accompany these packages in
licenses/opencv-python-headless/LICENSE-3RD-PARTY.txt.

Pillow-Heif 1.3.0 sources and wheel build scripts:
https://pypi.org/project/pillow-heif/1.3.0/#files
Native dependencies selected by the pillow-heif 1.3.0 build scripts:
libheif 1.21.2: https://github.com/strukturag/libheif/tree/v1.21.2
libde265 1.0.16: https://github.com/strukturag/libde265/tree/v1.0.16
x265 4.1: https://bitbucket.org/multicoreware/x265_git/src/4.1/
x265 4.1 archive: https://downloads.videolan.org/pub/videolan/x265/x265_4.1.tar.gz

licenses/pillow-heif/LICENSES_bundled.txt is the original upstream wheel
notice. Some version links in that notice predate the 1.3.0 build scripts.
ONNX Runtime (MIT): https://onnxruntime.ai/
Official versioned distributions:
https://pypi.org/project/onnxruntime/1.31.1/ (Linux)
https://pypi.org/project/onnxruntime/1.24.4/ (Windows/macOS)
ONNX Runtime's MIT and third-party notices are included in the package.

An application store account or a store signature is not needed to build
and run a modified version from the source. Build instructions are in
docs/development.md and docs/packaging.md.
