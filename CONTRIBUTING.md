# Contributing

Thank you for helping improve DocWen. Start with a focused issue before a large change so the intended
behavior, platform boundary, and test evidence can be agreed first.

Use a topic branch, keep commits scoped, and run the checks relevant to the changed package. A green unit
suite does not replace packaged, GUI, Office, or integration acceptance when those paths are affected.
Never commit private documents, local paths, credentials, caches, generated build trees, or maintainer
execution plans.

Pull requests should explain the user-visible result, tests run, supported platforms, breaking behavior,
and any real-host verification that remains pending. By contributing, you agree that your contribution is
licensed under the repository's AGPL-3.0 license.
